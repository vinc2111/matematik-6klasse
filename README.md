# Matematikværksted 6. klasse

Interaktivt matematiksite til 6. klasse. Hvert kapitel har en lille film, en model du kan trække i, teori og regler, fagord, et eksempel trin for trin, en fejlanalyse, opgaver på tre niveauer plus problemer, og hurtigregning.

Siden ligger på https://vinc2111.github.io/matematik-6klasse/

Alt ligger i index.html. Der er ingen eksterne filer, og siden henter intet udefra.
